🚨 IMPORTANT - POUR LANCER LE PROJET
═════════════════════════════════════

Le projet est PRÊT mais ne peut pas démarrer sans Docker !

Vous devez installer Docker et Docker Compose.


📦 INSTALLER DOCKER
═══════════════════

Ubuntu/Debian:
  curl -fsSL https://get.docker.com -o get-docker.sh
  sudo sh get-docker.sh
  sudo usermod -aG docker $USER
  newgrp docker

macOS:
  brew install --cask docker
  # Puis lancer Docker Desktop

Windows:
  Télécharger Docker Desktop: https://www.docker.com/products/docker-desktop


🚀 LANCER LE PROJET (après installation Docker)
════════════════════════════════════════════════

  cd /home/ahmed/Projets/old-school-project
  make demo

Cette commande va :
  1. Démarrer tous les conteneurs Docker
  2. Installer les dépendances
  3. Créer la base de données
  4. Charger les données de démo
  5. Créer l'utilisateur admin
