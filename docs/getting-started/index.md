## What You'll Learn

1. How to install using Docker or locally
2. How to set up the database
3. How to access the admin panel
4. How to load demo data

## Prerequisites

Before starting, make sure you have:

- PHP 8.3 or higher
- Docker & Docker Compose (recommended)
- MySQL 8.0+ (if not using Docker)
- Composer 2.x
- Git
